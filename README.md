# Sistema de Comedor Universitario - UNAMBA

Caso práctico de la asignatura Ingeniería de Software I.

## Objetivo

Simular el desarrollo colaborativo y el control de versiones de un sistema de comedor universitario mediante Git, GitHub y P4Merge.

## Plan de versiones

- **v1.0**: estructura base, README, requisitos y `config.py`.
- **v2.0**: menú del día (`feature-menu`).
- **v3.0**: reservas y aforo (`feature-reservas`) y resolución del conflicto de `config.py`.
- **v4.0**: pagos y ticket (`feature-pagos`).
- **v5.0**: reportes diarios (`main`).

## Participantes

- `master`: dueño del repositorio e integrador.
- `nombre`: desarrollador del menú y los pagos (sustituir por el colaborador real).
- `test`: desarrollador de reservas y aforo.

> Los módulos `menu.py`, `reservas.py`, `pagos.py` y `reportes.py` se añadirán en sus respectivas versiones, no en v1.0.
